# Qianyu One - Celestial Craft 3D (大明神机 · 乾舆一号空天神机 3D 交互典藏)

基于《永乐大典》风格古代飞碟（乾舆）营造图纸构建的高精度纯代码程序化 3D 展示。

## 规格尺寸
- 主盘直径：15.0m
- 通高：5.0m
- 装甲厚度：0.8m
- 起落架高度：2.3m（三足鼎立布置）
- 周身舷窗：24 扇步步锦中式棂花窗

## 交互特性
- **双模式渲染**：玄铁青铜 PBR 实物模式 vs 宣纸墨线工程蓝图模式一键切换
- **鼎足收折**：起落架 90° 液压折叠收拢进入腹仓（飞行/着陆状态）
- **零件分层拆解**：主盘体、天枢顶、步步锦舷窗、动力环与起落架爆炸拆解
- **自由视轨**：支持鼠标全方位旋转、缩放与视角复位
